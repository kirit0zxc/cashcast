# Проверка неопределённости первого эксперимента

До чтения ретроспективных результатов фиксируется единственный вариант:

- Точечный метод — только выбранный на validation, без изменения по поздним датам.
- На апрельском/майском срезах вычисляются 30-дневные векторы ошибки `факт - прогноз`, делённые на известный на cutoff масштаб потоков. Из них выбираются 200 целых траекторий с равным весом компаний, seed20261024. Не перемешивать дни независимо.
- Траектории центрируются по медиане каждого горизонта, чтобы p50 оставался выбранным точечным прогнозом. Это дополнительное допущение, его качество измеряется, а не гарантируется.
- Вероятности считаются как доля отрицательных траекторий с Jeffreys-сглаживанием (k+0.5)/(200+1). Риск по горизонту и по дням считается из одних траекторий.
- Проверка: срез30.06, только данные, доступные к этой дате, без добавления ошибок этого среза в библиотеку траекторий. Порог из0.05/0.1/0.2/0.3/0.5 по F2 с FPR<=25%; при ничьей более высокий порог.
- Сравнение Brier с текущим raw product и константой из calibration, на одинаковых доступных окнах при opening>=0. Дополнительно Accuracy/Precision/Recall/F1/F2, ROC-AUC/AP и reliability bins. Непригодные окна не считаются нулевым риском.
- Минимум для заявления калибровки: >=100fit окон и>=5положительных, >=50check окон и>=3положительных, Brier не хуже обоих ориентиров и отсутствие деградации на отдельных компаниях. Пока это не подтверждено, calibrated=false. Старые просмотренные периоды не дают независимой гарантии.
- В локальном адаптере библиотека ошибок применима только с30.06.2026, глобальные CatBoost-веса — с31.12.2025. Для ранних дат, планов/сценариев, короткой истории, неподдержанного горизонта и отсутствующих артефактов — текущий продукт без изменения его результата.
- При провале point-gate адаптер не переключает точку. Данный этап не разрешает автоматическое включение вероятности в production.
