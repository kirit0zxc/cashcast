## Data understanding (EDA)

- Прочитаны существующие аудиты и планы, исходный ZIP повторно проверен: dataset-audit-verified.json.
- Организаторский набор: 222420 операций, 150 компаний, 2024-10-01—2026-09-30; 16 компаний с отрицательными остатками, 99 несверок. Повторный аудит совпал.
- MoneyVis: один розничный клиент, отсутствие отрицательных остатков; подходит для внешней проверки потоков, не для измерения recall разрывов.
- Berka: множество розничных счетов, мало отрицательных окон; прежний CatBoost v2 не прошёл критерий выпуска. Нельзя считать ROC-AUC достаточным подтверждением.
- Август/сентябрь организаторского набора и Berka 1998 уже изучались. Новый случайный split не превращает их в нетронутый контроль.
- У организаторов новый контрольный файл ещё не получен.
