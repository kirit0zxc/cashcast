# 04 — прямой прогноз чистого денежного потока под MAE остатка

Статус: approved по автономному разрешению владельца; до запуска.

Гипотеза:01минимизирует MSE отдельных поступлений/списаний, а целевая оценка — MAE
остатка. Прогноз медианы накопленного netflow соответствует этой задаче ближе.
Риск02/03и старые веса не меняются; улучшение точечного остатка не объявляется
автоматически улучшением обнаружения разрыва.

Fit/validation/calibration/retrospective остаются как01. Те же признаки и строки,
никаких дополнительных будущих/отраслевых метаданных. Цель cumulative(in-out)/(scale*h).
CatBoost MultiQuantile(.1,.5,.9), depths4/6, iterations500,lr.04,l2=8,seed20261024.
Два фиксированных способа веса: равный суммарный вес компаний; либо этот вес,
умноженный на scale*h с нормировкой среднего веса1для соответствия денежному MAE.
Итого4кандидата; плюс прежняя фиксированная сетка смеси с текущей кривой.25/.5/.75.

Потоки in/out для диагностического DTO сохраняются из выбранного в01прямого
depth6; медиана остатка отдельная и не обязана равняться сумме математических
ожиданий потоков. В отчёте это явное ограничение, не бухгалтерская ошибка фактов.
Квантили q10/q90 этой модели не превращаются в совместную вероятность хотя бы
одного минуса; для неё нужны согласованные траектории и отдельная проверка.

Выбор по validation MAE остатка при macro-MAE компаний не хуже текущего более5%
и без ухудшения более10%на2срезах. Новый метод принимается только при>=5%улучшении.
После фиксации выбора поздние результаты только публикуются. Повторно изученные
периоды честно называются ретроспективными, новый контроль отсутствует.

Проверки причинности и сохранения поведения текущего продукта, детерминированность,
конечные денежные значения, неизменность прошлых артефактов, отчёты по7/14/30дням.
Без коммитов/push/production.
