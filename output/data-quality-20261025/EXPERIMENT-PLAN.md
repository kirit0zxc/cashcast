# Дополнительный эксперимент CashCast — 25.10.2026

План записан до расчёта новых метрик. Это исследовательское продолжение: сентябрь
уже изучался, нового нетронутого holdout нет. Исходники, продукт и прежние результаты
не изменяются. Исходные данные остаются локально; выгрузки — в gitignored data/raw.

## Единый протокол

Организаторский ZIP с проверкой SHA; 150 синтетических компаний. Те же окна B4:
30.04, 31.05, 30.06, 31.07.2026 validation, 31.08 → сентябрь retrospective.
Горизонт 30 дней; цель — исходный сверенный остаток, без удаления больших платежей,
изменения отрицательных остатков или обрезки контрольной цели. Ожидаем 517/122 окон.
Обучающие цели и подтверждающий остаток должны быть доступны до среза, embargo 37 дней.
Никакого смешения RUB с Berka/NN5/BPI/UK и никаких выводов о переносе на новые компании.

## Очистка и сравнения

Технические ошибки/дубли проверяются отдельно полным сканированием. Для эксперимента
clean означает маску недостоверных исторических потоков: если разность наблюдаемых
остатков не сходится с потоком между ними, весь интервал после предыдущего наблюдения
по текущий день помечается неизвестным. Маска возникает лишь в день обнаружения
несверки; будущее не меняет прошлые признаки. Наблюдаемые остатки сохраняются;
перенесённые остатки внутри несверенного интервала считаются неизвестными.
Регулярности остаются прежними: это ограниченная абляция числовых признаков.
Все модели оцениваются на одних исходных целях, даже при маскировании истории.

Фиксированные кандидаты:

- Закреплённые продуктовые 1.0-w84 и текущая 2.1-w84.
- Повтор последних 7/28/30 дней; weekday-среднее за 84 дня (raw/clean).
- Глобальная LightGBM по прежнему протоколу: 400 деревьев, 31 лист, lr .05,
  min_child_samples 200, lambda2 1; квантили .1/.5/.9 и потоки. Веса ансамбля .5/.5.
- Две абляции медианы LightGBM: без обрезки обучающей цели; clean с прежней обрезкой.
- Multioutput Ridge alpha=10 на признаках окна (raw/clean), 30 отдельных целей.
  Медианная импутация с missing indicators и StandardScaler обучаются только на train.
- Multioutput ExtraTrees на clean: 200 деревьев, max_depth 12, min_samples_leaf 20,
  max_features .8, seed 42. Импутация только train. Цели не обрезаются.

Фиксируем seed 42, максимум 4 вычислительных потока. На validation выбираем минимум
MAE; параметры/очистка не подбираются после просмотра новых результатов. Даже выигрыш
на сентябре не означает подтверждённое улучшение. Для ориентира старый строгий gate:
победа на ≥3/4 validation, gain≥5%, верхняя граница парного bootstrap по компаниям <0,
coverage .70–.90 при наличии интервалов. Point-only модели не получают статус готовности.

Метрики: MAE/RMSE/смещение/MAE30/WAPE, число компаний и окон, MAE по срезам/горизонтам,
парный bootstrap по компаниям 2000, матрица отрицательного дня и нового разрыва
при opening>=0. Для вероятностей новых экспериментов нет: ранее измеренные риски
разбираются отдельно; бинарный знак прогнозируемой кривой не называется вероятностью.

Проверки: воспроизведение B4 1.0 до 0.02 RUB, инварианты temporal mask/precision,
одинаковый support моделей, оригинальный truth, неизменность источников, независимое
чтение окончательного кода/отчёта Astra. Сохраняем агрегаты, исходники, версии и hashes;
числовые предсказания по окнам — только локально в data/raw, без pickle.
