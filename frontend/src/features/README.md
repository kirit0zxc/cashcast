# Минимальный frontend CashCast

Ночью frontend принадлежит A. Визуальную переработку команда делает утром;
серверный контракт и проверяемые пользовательские сценарии нужно сохранить.
Приложение использует настоящие API/worker/PostgreSQL, MSW в запуске не участвует.

- `auth/` — cookie-сессия, вход/выход и CSRF.
- `accounts/` — выбор счёта и координация обновлений после импорта/планов.
- `imports/` — preview ошибок банковской CSV и явный commit.
- `transactions/` — курсорный список и ручная категория с сохранением источника.
- `forecast/` — очередь/график/объяснения и четыре формы сценариев в ScenarioPanel.
- `planning/` — ручные планы, импорт обязательств и безопасная сверка оплат.

Перед редизайном прочитай `specs/frontend-handoff.md` и `specs/openapi.json` в корне
репозитория. Не заменять серверные расчёты браузерными формулами, не смешивать
неизвестную вероятность с нулём и не изменять сохранённую базу при редактировании.
Проверки: lint, typecheck, test:unit (Node24) и test:e2e на отдельном Compose.
