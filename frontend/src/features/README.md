# Папки фич фронтенда (владелец — Диана)

Каждая фича — отдельная папка с экраном и запросами к API. Типы ответов берутся из
`specs/openapi.json` (можно сгенерировать клиент) и фикстур `specs/examples/` (MSW).

- `imports/` — загрузка выписки, preview ошибок строк, подтверждение импорта.
- `transactions/` — список операций, фильтры, ручная правка категории.
- `forecast/` — график прогноза на 30 дней, риск, объяснение причин.
- `planning/` — плановые счета и события, форма добавления.
- `scenarios/` — «что если»: сравнение базовой и стрессовой кривых.

Правило: до часа 12 допустим MSW на фикстурах; к часу 12 подключается настоящий API,
к часу 20 — весь обязательный сценарий без моков. В финальном демо MSW выключен.
