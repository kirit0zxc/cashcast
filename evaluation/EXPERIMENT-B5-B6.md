# План эксперимента B5/B6, зафиксирован до запуска новых сравнений

Старт:23.10.2026 21:29UTC, исходная принятая модель B4/331b6f2.
Это новый этап разработки, не переименование просмотренного holdout.
Все данные синтетические организаторские с исходным SHA256 из dataset-participants.

## Разбиение

Принадлежность компании определяется только SHA256(company_id), первый байт mod5.
Остаток0 — отдельные компании для проверки переноса; остатки1–4 — development.
Метаданные будущего companies.csv не используются. Внутри каждой компании модель
видит только booked_on/balance_date/available_at<=as_of. Строки за границей каждой
фазы исключены даже из quality-gate фактической цели.

- История обучения каждого локального прогноза: только прошлое as_of, ограниченное окном метода.
- Выбор point-метода: development-компании, cutoffs31января,28февраля,31марта2026;
  цели следующие30дней, максимальная доступная дата30апреля2026.
- Fit калибровки: development, cutoffs30апреля и31мая2026, граница30июня2026.
- Проверка калибратора и выбор порога: development, cutoff30июня2026, граница31июля2026.
- Ретроспективный test: cutoffs31июля и31августа2026, граница30сентября2026,
  development и отдельные компании отчётно разделены. Август/сентябрь уже частично
  использовались B4: это НЕ независимый будущий период и не финальный новый holdout.
- Перенос калибровки на hash-split компании проверяется отдельно на тех же датах.
  Их собственная прошлая история допустима для локального прогноза, общие параметры
  и calibration fit не используют их целевые значения.

## Заранее выбранные кандидаты и критерии

Ориентиры: исходный baseline7дней и неизменённый seasonal-block-bootstrap-1.0-w84.
Новые альтернативы: среднее weekday с экспоненциальным весом (half-life28),
робастное weekday со срезом верхних5% исторических сумм, weekday с ограниченным
трендом (отношение последних4/предыдущих4 недель, shrink0.25, предел0.75–1.25).
Окно84 фиксировано; расширять сетку по ретроспективному test запрещено.
Выбор по MAE дневного остатка на одинаковых пригодных folds. Дополнительно RMSE,
ошибка конца горизонта, WAPE, median/per-company ошибки, short-history cohorts.
Новый метод принимается при >=5% выигрыше среднего MAE и отсутствии ухудшения
>10% на двух из трёх selection-cutoffs, runtime не более3x старого метода и
ограниченной памяти. Если условия не выполнены, сохраняется лучший подтверждённый
ориентир; исходная версия не удаляется из сравнений.

Калибраторы: исходный raw score; константа fit-prevalence с Beta(1,1) сглаживанием;
logit-intercept (slope1, bisection intercept); монотонный bin/PAVA с заранее заданными
границами0,.1,.2,.4,.6,.8,1 и shrink20 к fit-prevalence. Дневной и horizon fit отдельно.
Выбор калибратора по Brier calibration-check, на одних и тех же пригодных наблюдениях.
Отсутствие вероятности — отдельный допустимый продуктовый режим, не нулевая вероятность.

Минимальная опора: >=100fitfolds и>=5положительных, >=50checkfolds и>=3положительных
для horizon; для дневных вероятностей >=1000fitdays и>=10положительных и >=500checkdays
с>=5положительными. Иначе результат описывается как исследовательский, production None.
Режим продукта с вероятностью допускается только если Brier не хуже константы и raw
на check, без деградации на отдельной company-группе; неопределённость сравнения
оценивается bootstrap по company (seed20261024,500повторов), размер/число событий раскрыты.
При неподтверждённом качестве вероятность None с явной причиной; точечный прогноз,
плановые потоки и объяснения остаются доступны. После оценки test конфиг не подбирается.

Порог предупреждения выбирается на check из0.05,.1,.2,.3,.5 по F2 с ограничением
false-alarm доли<=25%; при ничьей больший порог. Если решения нет — предупреждение
по вероятности не рекомендовано, а не автоматически всегда положительное.
Отчёт: TP/FP/FN,precision/recall,F2,Wilson95% для долей, reliability bins,ECE,Brier,
paired company-bootstrap CI, lead time относительно первого наблюдаемого минуса.
Дневная и horizon вероятность должны удовлетворять union>=max(daily), но сравниваются
после всех преобразований, не только до clamp.

## Область применимости

Основной эксперимент horizon30; горизонты1/7/90/180 — профиль и отдельная проверка,
не переносим30-дневную калибровку на них без доказательства. Сценарии/явные будущие
счета отсутствуют в банковском эталоне: их вероятности не объявляем калиброванными.
Новые quality-gates и правило None описываются с version ID, не под прежним1.0.
Ограничения и исключённые folds публикуются. Никакой accuracy категорий без независимой
разметки. Ручной тестовый corpus имеет явно указанное происхождение.
