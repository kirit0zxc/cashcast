# Категоризация

RuleCategorizer реализует Categorizer через get_categorizer(). Порядок правил:
собственные переводы, зарплата, налог, комиссии, кредит/лизинг, аренда, выручка,
закупки. Существующая валидная категория сохраняется. Возвраты без связи с исходной
операцией остаются OTHER. Слова «НДС» недостаточно для TAX. Название контрагента
само по себе не является доказательством категории. ИНН не преобразуется в число.

Reason содержит имя правила, не исходное назначение. Confidence 0.85 обозначает
срабатывание эвристики, 0 — неизвестность; это не измеренная точность. В датасете нет
эталонной разметки, поэтому accuracy категорий по нему не заявляется.
