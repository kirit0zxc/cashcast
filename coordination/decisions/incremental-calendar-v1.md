# Дневная задача: incremental-calendar-v1

Основание — прямое поручение владельца 24.10.2026 реализовать недостающее обновление
без полного пересчёта. Ночная работа остановлена; её сроки/старые B7 задачи не возобновляются.
A реализует этот пакет самостоятельно по текущему поручению, включая необходимые
файлы forecasting/v2. Это не ACK агента B и не изменение его удалённой ветки.

Точный аддитивный контракт и ограничения: specs/incremental-forecast.md,
OpenAPI CalculationOut. Общий modules/contracts.py и frozen legacy_v1 неизменны.
Основная математика/версия/seed сохраняются. Первая очередь — календарные данные;
инкрементальная обработка новой фактической банковской истории не обещается.
Прежде чем main: полный local suite, UI без моков, два независимых reviewer и
третий verifier. Merge/Approve выполняет человек.
