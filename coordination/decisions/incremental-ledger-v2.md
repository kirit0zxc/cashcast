# Решение incremental-ledger-v2 — 24.10.2026

Владелец прямо поручил A довести частичное обновление при загрузке фактических операций.
Это дневная задача в agents/a-incremental-forecast, расширяет calendar-update-v1.
Запись фиксирует разрешение владельца, не является ACK агента B. Чужие ветки не меняем.

Алгоритм/границы: specs/incremental-forecast.md. Версия математической модели не меняется:
совпадение с frozen legacy проверяется независимо. Старый checkpoint требует full.
Дополнение OpenAPI — nullable диагностические счётчики calculation без удаления полей.

Перед push: локальные проверки, два независимых рецензента и третий верификатор.
Main сливает человек. Сохраняем приватность и согласованный режим экономии Actions.
OpenRouter-ассистент пока обсуждается: ключи не запрашиваем, интеграцию не реализуем.
