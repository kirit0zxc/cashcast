# Ночь24.10: приватный репозиторий и лимит Actions

Прямое указание владельца: скоро исчерпается GitHub Actions; разрешено выбрать
публичность либо продолжить при недоступных CI-проверках, обязательно уведомив B.
A выбрал сохранить cashcast приватным. Это решение действует для текущей ночи.

GitHub Actions больше не обязательный барьер при интеграции этой ночью, если проверки
не запустились/остановлены из-за квоты или отсутствуют при экономии оставшихся минут.
Не делать ручной workflow_dispatch каждого status/docs/push и не перезапускать
однотипный отказ квоты. Имеющийся результат записывать честно: success/failed/
cancelled/not_run; причина quota только при наличии соответствующего сообщения.
Нельзя выдавать отсутствие run за зелёный CI. Уже запущенные полезные проверки можно
дождаться; устаревшие дубли допускается отменить ради экономии.

Обязательны локальные профильные тесты, один независимый reviewer и проверка общего
кандидата A. Перед integration фиксировать точный SHA/tree, команды и результаты,
неизменную базу. Для изменённого приложения — реальные PostgreSQL/worker/Compose/E2E
по затронутому пути; для status/docs — облегчённый контроль метаданных. Истинные
падения тестов/линтера/сборки исправлять, а не относить к квоте. Не прошедший локальные
проверки код нельзя объявлять READY/VERIFIED.

Основной workflow не удаляется и не выключается, права/видимость не меняются,
новые расходы запрещены. Main по-прежнему одобряет и сливает только человек.
Утром указать, какие SHA прошли Actions, а какие приняты по этому исключению.
